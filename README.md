# Insider Game

A web-based social deduction game.

## Tech Stack
- **Client:** React, Vite
- **Server:** Node.js, Socket.io

## Setup

1.  **Install Dependencies:**
    ```bash
    cd client && npm install
    cd ../server && npm install
    ```

2.  **Run Server:**
    ```bash
    cd server
    npm start
    ```

3.  **Run Client:**
    ```bash
    cd client
    npm run dev
    ```
